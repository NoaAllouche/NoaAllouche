## [🎮 Text Adventure World](https://github.com/NoaAllouche/Text-Adventure-World.git)

A 2-player cooperative console adventure game developed in C++.

- Includes puzzle-solving mechanics, spring physics, obstacle pushing, riddles, bombs, switches, and dark rooms.
- Built using object-oriented programming and dynamic game logic.
- Supports file-based room loading and interactive gameplay mechanics.

---

## [📈 GuessMarket Project](https://github.com/NoaAllouche/GuessMarket.git)

A collaborative Java prediction-market simulation built using a modular, object-oriented architecture.

- Implements market event management, share trading, and pricing mechanisms such as LMSR and Order Book.
- Includes a JavaFX desktop interface and a client–server architecture using HTTP communication.
- Uses XML and JSON for event configuration and data exchange, with support for user accounts, trading history, and market resolution.

---

## [♞ CheckMate Project](https://github.com/NoaAllouche/CheckMate.git)

A chess knight path-finding project developed in C.

- Implements recursive tree traversal, linked lists, dynamic memory allocation, and backtracking algorithms.
- Generates all valid knight moves and searches for a path covering the entire chess board.
- Includes visualization of knight traversal paths.

---

## [🐂 Bulls and Cows Solver](https://github.com/NoaAllouche/Bulls-And-Cows-Solver.git)

A Python implementation of the classic Bulls and Cows game solver.

- Generates valid unique-digit codes and evaluates Bulls/Cows feedback.
- Dynamically filters candidates after each guess.
- Includes multiple solving strategies, including a Knuth-based optimal guessing algorithm.
